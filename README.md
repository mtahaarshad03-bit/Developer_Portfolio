# Muhammad Taha — Developer Portfolio

A responsive developer portfolio landing page built with HTML5, CSS3, and vanilla JavaScript.

## Run locally
1. Extract `Developer_Portfolio.zip`.
2. Open the extracted folder in VS Code.
3. Open `index.html` with Live Server (recommended), or open it in a modern browser.
4. Internet access is needed for Google Fonts. The design itself does not require a backend.

## Assignment requirements
- [x] High-conversion portfolio landing page with clear visual hierarchy
- [x] Developer hero with introduction, headline, availability badge, and social links
- [x] Interactive technical skills showcase
- [x] Featured projects grid
- [x] Working in-page project preview modals
- [x] Responsive navigation for mobile and desktop
- [x] Smooth scrolling, hover transitions, and keyframe animations
- [x] Contact call-to-action and footer

## IMPORTANT — personalize before publishing
1. In `index.html`, replace `hello@example.com` with your real professional email.
2. Replace the generic GitHub and LinkedIn profile URLs with your actual profile URLs.
3. Add your real hosted project URLs if you have deployed projects. The current project buttons open interactive in-page summaries; they do not claim to be externally hosted live deployments.
4. Replace or update project descriptions and skill tags to match your final portfolio.
5. The availability badge is editable copy; change it if you are not currently available.
